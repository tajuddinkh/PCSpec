# PCSpec Portable v3.0

PCSpec Portable v3.0 is the stable portable Windows release focused on clear, local hardware and system information without unnecessary background services or online dependencies.

## Highlights

- Clean **Summary** view for essential specifications
- **Detailed** report for core computer, Windows, CPU, RAM, graphics and storage information
- **Extra** report for additional physical hardware
- **Full Report** for complete combined system information
- **Others** page for advanced Windows-level and diagnostic details
- Professional **About** page with version, build and privacy information
- Professional embedded application icon
- Conservative physical USB-port filtering to avoid presenting internal USB functions as external sockets
- Battery hardware, capacity, health and cycle information where Windows exposes it
- LAN and Wi-Fi hardware identification and connection information
- Display and active display-connection reporting
- TPM presence, availability and specification reporting where Windows exposes it
- Copy, Save, Save All and Refresh controls
- Portable operation with no installation required

## Privacy and offline operation

PCSpec Portable operates locally. It uses no telemetry, analytics, cloud services, online update checks, internet hardware/vendor lookups, nearby Wi-Fi scanning or background network communication. Hardware and system information is obtained from local Windows sources.
